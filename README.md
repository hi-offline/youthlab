# YouthLab – Female Empowerment

Educational website about female empowerment, highlighting women's achievements, history, and social impact.

[🇺🇸 English](#english) | [🇧🇷 Português](#português)

---

## English

### About

**YouthLab – Female Empowerment** is an educational web project developed to explore women's history, achievements, representation, and social impact.

The project presents historical figures, relevant data, and educational content in an interactive and accessible format, combining technology and education to encourage reflection on female empowerment and the role of women in society.

### Features

* Interactive presentation of historical women
* Educational content about women's achievements and contributions
* Data visualization focused on gender-related social topics
* Interactive carousel for historical figures
* Video-based visual introduction
* Responsive interface for different screen sizes

### Technologies

* HTML5
* CSS3
* JavaScript
* Node.js / npm
* Embla Carousel

## Português

### Sobre

**YouthLab – Female Empowerment** é um projeto web educacional desenvolvido para explorar a história das mulheres, suas conquistas, representatividade e impacto social.

O projeto apresenta figuras históricas, dados relevantes e conteúdos educativos de forma interativa e acessível, combinando tecnologia e educação para estimular a reflexão sobre o protagonismo feminino e o papel das mulheres na sociedade.

### Funcionalidades

* Apresentação interativa de mulheres históricas
* Conteúdo educativo sobre conquistas e contribuições femininas
* Visualização de dados relacionados a questões sociais e de gênero
* Carrossel interativo de figuras históricas
* Introdução visual baseada em vídeo
* Interface responsiva para diferentes tamanhos de tela

* JavaScript
* Node.js / npm
* Embla Carousel
